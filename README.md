# Tilt-Rotor-VTOL-Drone

Project Overview
This repository contains the SolidWorks design files for a custom VTOL Tilt-Rotor UAV. The architecture of this drone is heavily inspired by the Zipline P2 (Platform 2), utilizing a high-efficiency tilt-rotor configuration for precise hover and rapid long-distance flight.

Current Status: 🏗️ Work in Progress (Design Phase)
This is a purely digital design at this stage. The CAD models focus on the mechanical synchronization of the tilting rotors and the integration of a functional internal cargo delivery system.

Key Design Features
1. Zipline-Inspired Tilt Mechanism
Unlike traditional VTOLs, this design uses a streamlined tilting assembly for the primary rotors. This allows the aircraft to take off vertically like a helicopter and transition into a high-speed wing-borne flight mode.

2. Integrated Winching System
A core feature of this CAD model is the active winching mechanism.
Precision Delivery: Designed to lower payloads via a tether while the drone maintains a steady hover at altitude.
Mechanical Integration: The winch drum is positioned to maintain the drone's center of gravity (CoG) during deployment.

3. Internal Cargo Bay
The fuselage includes a dedicated cargo bay optimized for standardized package dimensions.
Aerodynamic Shielding: The cargo is fully enclosed during transit to minimize drag.

4. Minimize the number of motors
Although there are 4 propulsion motors to ensure maximum cargo capacity and weight, it is designed with only 3 tilt motors by mechanically linking the rear motors. This saves weight and complexity on the drone.
